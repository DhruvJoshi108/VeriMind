## Current feature inventory (not period-attributed)

- Claim segmentation filters greeting-like text, questions, short fragments, and some hedged statements.
- The verification pipeline retrieves evidence and classifies claim/evidence pairs, then returns verdicts, risk scores, and explanations.
- Retrieval combines local TF-IDF search with a selectable web-search backend.
- The API exposes document verification and report lookup; the dashboard renders claim-level results.
- SQLite stores a report and its claims and evidence.
