Welcome to VERIMIND

An evidence-grounded claim verification project. Start the API, add the dashboard if you want the visual interface, and keep the internal modules in their folders.

Open API docs ↗ Open dashboard ↗ Read setup guide →

Run the commands below from the project root. API/dashboard links need their local services running.

The happy path

Just the steps needed to try the app. You do not need to run every Python file.

01Once

Open the project folder

Use the project’s own environment, not the backup folder’s Python.

Set-Location "C:\path\to\VERIMIND"
02First setup

Prepare Python

Do this once if you don't already have a working project environment.

py -3.11 -m venv .venv .\.venv\Scripts\python.exe -m pip install -r requirements.txt -r dashboard\requirements.txt
03Quick check

Try the demo

Runs one sample claim through the local verification pipeline.

.\.venv\Scripts\python.exe scripts\demo.py
04Terminal 1

Start the API

Keep this terminal open while using the app.

.\.venv\Scripts\python.exe -m uvicorn api.main:app --reload
05Optional · Terminal 2

Start the dashboard

Open a second terminal in the same project folder.

.\.venv\Scripts\python.exe -m streamlit run dashboard\app.py
06When ready

Run the checks

Run from the project folder, not from a parent workspace.

.\.venv\Scripts\python.exe -m pytest -q
07Optional

Explore evaluation

Use the dev split to evaluate; index-building and training are separate workflows.

.\.venv\Scripts\python.exe eval.py --split dev

A little map of the folders

Each folder has a job. Most contain components imported automatically.

APIapi/

FastAPI application, endpoints, request schemas, and auth dependencies.

VMverimind/

Core claim, retrieval, NLI, scoring, and verification pipeline modules.

UIdashboard/

Streamlit entry point, pages, and its API client. Pages load automatically.

▶scripts/

Optional commands for demo, training, data preparation, and index building.

✓tests/

Automated checks. Run them together with pytest.

EVeval/

Evaluation support code and saved evaluation outputs.

Rretrieval/

Retrieval utilities and an optional FAISS index smoke test.

DBdata/

Corpora, local indexes, and evaluation cases—not scripts to execute.

MLartifacts/

Saved model files loaded by the pipeline; see model details in the guide.

↗deploy/

Docker and deployment configuration, separate from local startup.

idocs/

Project notes and planning documents.

CI.github/

CI workflow runs checks automatically on pushes and pull requests.

↗results/

Saved evaluation summaries and confusion-matrix output.

!
Important: don’t run modules one by one

Files like api/deps.py and verimind/pipeline.py are imported by the app. Start the API with Uvicorn; start the dashboard with Streamlit. Use the same .venv for every command—don't select Python from __remove_code_git. Notebooks are optional and are not needed for normal use.
